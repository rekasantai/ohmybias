# Oh My Bias! — Sarawak Edition

Developed by **RekaSantai**.

A mobile-first interactive web game that teaches **cognitive bias**, **wicked problem solving**, and **team alignment**, localised with authentic Sarawakian settings, stakeholders, and *Pua Kumbu*-inspired visuals.

## Features
- **5 Sarawakian Episodes**: From Kuching night-market flood dilemmas to Ulu Baram longhouse eco-tourism, Serian pepper farms, the Rajang basin, and a statewide digital service finale.
- **4-Phase Gameplay Loop**: *Kopitiam/Ruai Briefing → Bias Radar → Wicked Problem Toolkit → Team Alignment & Debrief*.
- **Live Compass Meters**: Track **Team Alignment**, **Community Trust**, and **Long-Term Impact** across every decision.
- **Kamus (In-Game Glossary)**: Quick reference for cognitive biases, wicked problem concepts, and Sarawakian terms.
- **Zero-Build Static Architecture**: Pure HTML5, CSS3, and ES6+ Modules with synthesized Web Audio API sound effects and `localStorage` persistence.

## Running Locally
Simply **double-click `index.html`** to open and play directly in any modern browser (Chrome, Edge, Safari, Firefox)—no web server required!

You can also host the folder on any static host (GitHub Pages, Netlify, Cloudflare Pages) or run a local server if you edit the ES module files under `js/` and regenerate `js/bundle.js`.
